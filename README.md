# Tree-Diagram-to-Simulate-Instance-Creation---A-Creative-Writing-Exercise
This script is designed to simulate Object Instance creation as described in my Biomathematics Essay. 

The idea is that variable count dictates how many instances are created within an object.

********************* Warning *********************
Currently the script is unable to handle less than 2 generations of parent:child relationships. Therefore the code will crash if zero children are produced on the first run (which happens surprisingly often). My way around it has just been to run the script until I have a sufficient number of parent child relationships.
